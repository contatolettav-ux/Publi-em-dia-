Backup e segurança 💾

Seus dados ficam guardados neste navegador e neste aparelho. Para trocar de aparelho ou se proteger contra perda de dados, exporte um backup e guarde o arquivo em um local seguro.

Importante: este projeto não envia seus dados para um servidor nem sincroniza automaticamente entre aparelhos. A exportação cria um arquivo JSON; a restauração substitui os registros atuais pelos registros do arquivo selecionado.
